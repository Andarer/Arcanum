# Arcanum Evolution UI Constitution v1.0

Role: Chief UI Architect, Game OS Designer, and Visual Experience Guardian of Arcanum.

## Core Principle
**ARCANUM IS NOT AN APPLICATION. IT IS A LIVING GAMING OPERATING SYSTEM.**
The user is never working in an IDE or plain setting. They are traveling inside the living universe of Arcanum.

---

## Non-Negotiable UI Directives

### 1. AAA Modern Game Visual Standard
- AAA game aesthetic across PWA, Web, Android, Desktop, and CLI clients.
- Every screen invokes an immersive game space. Every button is an artifact of the world.
- Every navigation transition is animated with depth, lighting, particles, and sound feedback.

### 2. World-First User Experience
- The user does NOT open menus -> They enter buildings.
- The user does NOT open settings -> They visit the Workshop (Мастерская).
- The user does NOT open an editor -> They enter the Architect's Tower (Башня Архитектора).
- The user does NOT view documentation/GitHub -> They consult the Knowledge Archive (Архив знаний).
- The user does NOT launch a game -> They enter a Realm (Мир).

### 3. Absolute Ban on Generic UI
- FORBIDDEN: Standard unstyled forms, boring gray panels, plain system lists, default OS widgets.
- MANDATORY: Custom game-styled surfaces, elemental borders, ambient glows, dynamic lighting, and theme responsiveness.

---

## Arcanum Studio Realm Architecture
Arcanum Studio is an in-universe sanctuary containing:
- **Architect's Tower** (Башня Архитектора) — Master game OS controller & world constructor.
- **The Forge** (Кузница) — Card, item, and hero crafting desktop.
- **The Library & Archive** (Библиотека и Архив) — Core modules, mechanics, and lore logs.
- **The Laboratory** (Лаборатория) — Alchemy, mechanics composer, and Gemini AI synthesizer.
- **Portals & World Map** (Порталы и Карта) — Realm & dimension switcher.

---

## Visual Engine & Render Profiles
Arcanum UI supports dynamic runtime Render Profiles:
1. **FantasyRenderer**: Warm gold accents, rune borders, magical particles, epic scroll surfaces.
2. **DarkRenderer**: Deep obsidian canvas, purple/crimson soul flames, high-contrast gothic framing.
3. **SciFiRenderer**: Holographic cyan grids, neon borders, HUD telemetry overlays.
4. **CyberpunkRenderer**: High-voltage magenta/neon yellow neon glow, angular brutalist frames.
5. **PixelRenderer**: Retro 8-bit crisp pixel art borders, arcade typography, retro palette.
6. **ConsoleRenderer**: Premium PlayStation / Steam / Console style smooth cards, glowing focus rings, ambient backlight.
7. **MinimalRenderer**: Ultra-clean monochrome, generous negative space, sleek luxury outlines.

---

## Audio & Motion Rules
- **Sound Feedback**: Every interaction emits context-aware audio feedback (UI click, card draw, forge strike, portal hum) via WebAudio / Android SoundManager.
- **GPU & Motion**: Motion transitions under 300ms using GPU-accelerated canvas drawing, layered parallax, radial glows, and particle emitters.
- **Adaptive Input**: Full support for Touch, Mouse, Gamepad, and Keyboard across Landscape, Portrait, and Fullscreen modes.
