# Arcanum - Card MMORPG & PWA

**Arcanum** — это коллекционная карточная ККИ MMORPG с пошаговыми сражениями на арене, созданием уникальных карт, системой квестов, миром для исследования и полноценной поддержкой **PWA (Progressive Web App)** для офлайн-игры в браузере и на Android.

---

## 🌟 Основные особенности и возможности

- **🎴 Коллекция Карт (`CardCollectionScreen`)**:
  - Карты разделены по типам (`Hero`, `Creature`, `Item`) и редкости (`Common`, `Rare`, `Epic`, `Legendary`, `Mythic`).
  - Фильтрация по типам и редкости, динамический поиск по названию и описаниям.
  - Улучшение уровня карт с повышением характеристик (`HP`, `STR`, `DEF`).

- **⚔️ Пошаговые Сражения на Арене (`BattleScreen` & `BattleViewModel`)**:
  - Тактический пошаговый бой против врагов с уникальным AI (Гоблин-Берсерк, Скелет-Воин, Некромант).
  - Использование карт из активной колоды, атак, навыков и зелий.
  - Анимированный урон и расчёт защиты/атак.

- **🏰 Мир и Исследование (`WorldScreen`)**:
  - Интерактивная карта мира с локациями для исследования и специальными сражениями.

- **🔨 Крафт и Магазин (`CraftScreen`, `ShopScreen`, `ChestScreen`)**:
  - Алхимия и объединение карт для создания редких экземпляров.
  - Магазин бустерпаков и расходуемых предметов.
  - Открытие сундуков с наградами.

- **🎠 Игровые Карусели (Game Carousels)**:
  - Интерактивные горизонтальные карусели событий, боссов и акций на базе `LazyRow` в Jetpack Compose и CSS Touch-Snap в PWA.

- **⚔️ Онлайн PVP Арена (`PVP Engine`)**:
  - Рейтинговые поединки со случайным подбором соперников, расчётом MMR рейтинга и уникальными лигами.

- **💎 Кристальный Кликер (`Tap Clicker Engine`)**:
  - Быстрая добыча золота и маны кликами по кристаллу с всплывающим уроном и закупкой авто-майнеров.

- **🎯 Аркадный Тир (`Arcade Shooter Engine`)**:
  - Мини-игра на HTML5 Canvas по уничтожению падающих монстров касаниями на скорость.

- **🎵 Встроенный Синтезатор Звука (Web Audio API)**:
  - Динамическая генерация 8-битных SFX для ударов, магии, кликов и открытия сундуков без использования тяжёлых файлов.

- **📱 Мобильный Игровой Нижний Навбар (Mobile RPG Action Bar)**:
  - Фиксированная нижняя панель действий с неоновым свечением и быстрой переключаемостью между 9 разделами.

- **✨ Стартовая Карусель-Обучение (`Onboarding Carousel`)**:
  - Интерактивный вводный экран с анимациями, горизонтальными тач-свайпами, светящимися индикаторами и полным описанием механик.

- **📺 Полноэкранный Режим & Адаптивные Свайпы (Fullscreen & Touch Gestures)**:
  - Полная поддержка `enableEdgeToEdge()` в Android Compose и Fullscreen API в PWA для максимального погружения в игру.

- **🌐 PWA Офлайн Браузерная Версия (`app/src/main/assets/pwa`)**:
  - Автономный Service Worker (`sw.js`) и PWA-манифест (`manifest.json`).
  - Полностью идентичная игровая механика на HTML5/CSS3/JavaScript ES6.
  - Встроена в Android-приложение через `PwaWebScreen` WebView.

## 🛠 CI/CD & GitHub Actions

1. **PWA GitHub Pages Deploy (`.github/workflows/deploy-pwa-gh-pages.yml`)**:
   - Автоматически публикует PWA-версию на GitHub Pages при каждом пуше в ветку `main` или `master`.

2. **Android Release APK Workflow (`.github/workflows/build-release-apk.yml`)**:
   - Собирает отладочный/релизный APK и создает релизы в GitHub Releases при пуше тегов (например, `v1.0.0`).

## 🛠 Технологический стэк

### Android Native App
- **Язык**: Kotlin 2.0+
- **UI Фреймворк**: Jetpack Compose (Material Design 3)
- **База Данных**: Room DB (SQLite) с KSP
- **Архитектура**: MVVM (Model-View-ViewModel) + StateFlow & Coroutines
- **Навигация**: Navigation Compose c type-safe маршрутами

### Browser / PWA Version
- **HTML5 & CSS3**: Высококонтрастная тёмная фэнтези тема с адаптивной сеткой Grid & Flexbox
- **JavaScript**: ES6 Vanilla JS, LocalStorage для сохранения игрового прогресса
- **PWA Engine**: Service Worker Caching, Manifest v3

## 🚀 Сборка и Запуск

### Запуск Android Приложения:
```bash
./gradlew assembleDebug
```

### Доступ к PWA Версии & Деплой на GitHub Pages:
1. **Онлайн PWA Версия на GitHub Pages**:
   - В корне репозитория создан `index.html`, который автоматически загружает PWA-игру `app/src/main/assets/pwa/index.html`.
   - В настройках GitHub репозитория перейдите в **Settings ➔ Pages**:
     - В поле **Source** выберите **GitHub Actions** (для автоматической сборки PWA и APK).
     - Если выбрано **Deploy from a branch**, выбирайте ветку `main` и папку `/ (root)`.
2. **Локальный Браузер**: Откройте файл `index.html` или `app/src/main/assets/pwa/index.html` в любом современном браузере.

## 📲 Установка Android APK

1. **Прямое скачивание с сайта PWA**:
   - На главной странице PWA или в разделе **Настройки** нажмите золотую кнопку **📲 Скачать APK (Android Приложение)**.
   - Загрузится файл `arcanum.apk`.
2. **Скачивание из GitHub Actions / Releases**:
   - Перейдите на вкладку **Actions** в репозитории GitHub.
   - Выберите последний успешный запуск **Deploy Arcanum PWA to GitHub Pages** или **Build & Release Android APK** и скачайте артефакт с готовым `.apk`.
3. **Установка на смартфон**:
   - Откройте скачанный `.apk` файл на устройстве Android.
   - Всплывет предупреждение Android о неизвестном источнике — нажмите **Разрешить для этого источника (Allow from this source)**.
   - Нажмите **Установить** и запускайте Arcanum!
