# Arcanum - Card MMORPG & PWA

**Arcanum** — это коллекционная карточная ККИ MMORPG с пошаговыми сражениями на арене, созданием уникальных карт, системой квестов, миром для исследования и полноценной поддержкой **PWA (Progressive Web App)** для офлайн-игры в браузере и на Android.

---

## 🌟 Основные особенности и возможности

- **🎴 Коллекция Карт (`CardCollectionScreen`)**:
  - Карты разделены по типам (`Hero`, `Creature`, `Item`) и редкости (`Common`, `Rare`, `Epic`, `Legendary`, `Mythic`).
  - Фильтрация по типам и редкости, динамический поиск по названию и описаниям.
  - Улучшение уровня карт с повышением характеристик (`HP`, `STR`, `DEF`).

- **⚔️ Пошаговые Сражения на Арене (`BattleScreen` & `BattleViewModel`)**:
  - Тактический пошаговый бой против врагов с уникальным AI (Гоблин-Берсерк, Скелет-Воин, Некромант).
  - Использование карт из активной колоды, атак, навыков и зелий.
  - Анимированный урон и расчёт защиты/атак.

- **🏰 Мир и Исследование (`WorldScreen`)**:
  - Интерактивная карта мира с локациями для исследования и специальными сражениями.

- **🔨 Крафт и Магазин (`CraftScreen`, `ShopScreen`, `ChestScreen`)**:
  - Алхимия и объединение карт для создания редких экземпляров.
  - Магазин бустерпаков и расходуемых предметов.
  - Открытие сундуков с наградами.

- **🌐 PWA Офлайн Браузерная Версия (`app/src/main/assets/pwa`)**:
  - Автономный Service Worker (`sw.js`) и PWA-манифест (`manifest.json`).
  - Полностью идентичная игровая механика на HTML5/CSS3/JavaScript ES6.
  - Встроена в Android-приложение через `PwaWebScreen` WebView.

## 🛠 Технологический стэк

### Android Native App
- **Язык**: Kotlin 2.0+
- **UI Фреймворк**: Jetpack Compose (Material Design 3)
- **База Данных**: Room DB (SQLite) с KSP
- **Архитектура**: MVVM (Model-View-ViewModel) + StateFlow & Coroutines
- **Навигация**: Navigation Compose c type-safe маршрутами

### Browser / PWA Version
- **HTML5 & CSS3**: Высококонтрастная тёмная фэнтези тема с адаптивной сеткой Grid & Flexbox
- **JavaScript**: ES6 Vanilla JS, LocalStorage для сохранения игрового прогресса
- **PWA Engine**: Service Worker Caching, Manifest v3

## 🚀 Сборка и Запуск

### Запуск Android Приложения:
```bash
./gradlew assembleDebug
```

### Доступ к PWA Версии:
1. Запустите приложение Android и перейдите в **Настройки -> Запустить PWA**.
2. Или откройте файл `app/src/main/assets/pwa/index.html` в любом современном браузере.
