# Arcanum UI Web Components Catalog v2.6

## Arcanum UI Web Components (`arcanum-ui.js`)

All UI components are registered standard Web Components with custom element tags:

| Tag Name | Custom Element Class | Description |
| :--- | :--- | :--- |
| `<ar-button>` | `ArButton` | Game action button with native haptic feedback |
| `<ar-panel>` | `ArPanel` | In-world surface container with render profile borders |
| `<ar-card>` | `ArCard` | Collectible card element displaying artwork & stats |
| `<ar-inventory>` | `ArInventory` | Inventory grid item slot container |
| `<ar-dialog>` | `ArDialog` | In-world dialogue window for NPCs and quests |
| `<ar-dialogue>` | `ArDialogue` | In-world narrative dialogue container |
| `<ar-quest>` | `ArQuest` | Task tracker item container |
| `<ar-window>` | `ArWindow` | Draggable or static game window overlay |
| `<ar-map>` | `ArMap` | World map location node element |
| `<ar-character>` | `ArCharacter` | Player hero avatar panel with stats bars |
| `<ar-world>` | `ArWorld` | World realm container |
| `<ar-menu>` | `ArMenu` | Navigation bar / menu container |
| `<ar-hud>` | `ArHud` | Top HUD bar (HP, Gold, Level, Gems) |
| `<ar-notification>` | `ArNotification` | In-game banner alert element |
| `<ar-modal>` | `ArModal` | Overlay modal card |
| `<ar-toast>` | `ArToast` | Floating toast alert banner |
| `<ar-context-menu>` | `ArContextMenu` | Radial / drop context menu |
| `<ar-tooltip>` | `ArTooltip` | Stat hover preview overlay |
| `<ar-craft>` | `ArCraft` | Alchemy forge crafting recipe card |
| `<ar-battle>` | `ArBattle` | Combat arena layout container |
| `<ar-editor>` | `ArEditor` | Arcanum Studio live card & world editor |
| `<ar-dock>` | `ArDock` | Floating bottom application dock |
| `<ar-sidebar>` | `ArSidebar` | Desktop & Tablet navigation sidebar |
| `<ar-toolbar>` | `ArToolbar` | Quick actions action bar |
| `<ar-status-bar>` | `ArStatusBar` | System & device status bar |
| `<ar-console>` | `ArConsole` | In-game developer console overlay |
| `<ar-settings>` | `ArSettings` | System preferences & render profile panel |
| `<ar-library>` | `ArLibrary` | Interactive documentation and lore reader panel |
| `<ar-marketplace>` | `ArMarketplace` | Community modules, themes and asset store |
| `<ar-git>` | `ArGit` | GitHub synchronization & CI/CD pipeline manager |
| `<ar-ai>` | `ArAI` | Embedded AI Architect assistant chat overlay |
| `<ar-explorer>` | `ArExplorer` | File system & workspace resource navigator |
