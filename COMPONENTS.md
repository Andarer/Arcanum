# Arcanum UI Web Components Catalog v3.4

## ArDesign System Web Components (`arcanum-ui.js`)

All UI components are registered standard Web Components with custom element tags:

| Tag Name | Custom Element Class | Description |
| :--- | :--- | :--- |
| `<ar-app>` | `ArApp` | Universal root application container |
| `<ar-scene>` | `ArScene` | Immersive 2D/3D scene container |
| `<ar-splash>` | `ArSplash` | Interactive loading splash screen |
| `<ar-button>` | `ArButton` | Game action button with audio & haptic feedback |
| `<ar-panel>` | `ArPanel` | In-world surface container with render profile borders |
| `<ar-card>` | `ArCard` | Collectible card element displaying artwork & stats |
| `<ar-list>` | `ArList` | Vertical items list layout container |
| `<ar-grid>` | `ArGrid` | Responsive grid container |
| `<ar-dialog>` | `ArDialog` | In-world dialogue window for NPCs and quests |
| `<ar-dialogue>` | `ArDialogue` | In-world narrative dialogue container |
| `<ar-quest>` | `ArQuest` | Task tracker item container |
| `<ar-window>` | `ArWindow` | Draggable floating game/applet window |
| `<ar-map>` | `ArMap` | World map location node element |
| `<ar-character>` | `ArCharacter` | Player hero avatar panel with stats bars |
| `<ar-world>` | `ArWorld` | World realm container |
| `<ar-menu>` | `ArMenu` | Navigation bar / menu container |
| `<ar-hud>` | `ArHud` | Top HUD bar (HP, Gold, Level, Gems) |
| `<ar-tabs>` | `ArTabs` | Navigation tab bar container |
| `<ar-dock>` | `ArDock` | Floating application workspace dock |
| `<ar-toolbar>` | `ArToolbar` | Quick actions toolbar |
| `<ar-sidebar>` | `ArSidebar` | Collapsible sidebar container |
| `<ar-inventory>` | `ArInventory` | Inventory grid item slot container |
| `<ar-chat>` | `ArChat` | In-game messaging & chat container |
| `<ar-camera>` | `ArCamera` | Scene camera viewport controller |
| `<ar-scanner>` | `ArScanner` | QR / AR scanning viewport |
| `<ar-marketplace>` | `ArMarketplace` | Community market & package catalog |
| `<ar-library>` | `ArLibrary` | Specifications & docs library viewer |
| `<ar-explorer>` | `ArExplorer` | Universe map & files explorer |
| `<ar-settings>` | `ArSettings` | System preferences panel |
| `<ar-console>` | `ArConsole` | Command palette terminal |
| `<ar-terminal>` | `ArTerminal` | Interactive developer CLI console |
| `<ar-developer>` | `ArDeveloper` | Developer tools & state inspector |
| `<ar-profiler>` | `ArProfiler` | Performance & memory profiler |
| `<ar-toast>` | `ArToast` | Floating toast alert banner |
| `<ar-notification>` | `ArNotification` | In-game banner alert element |
| `<ar-modal>` | `ArModal` | Overlay modal card |
| `<ar-context-menu>` | `ArContextMenu` | Radial / drop context menu |
| `<ar-tooltip>` | `ArTooltip` | Stat hover preview overlay |
| `<ar-craft>` | `ArCraft` | Alchemy forge crafting recipe card |
| `<ar-battle>` | `ArBattle` | Combat arena layout container |
| `<ar-editor>` | `ArEditor` | Arcanum Studio live card & world editor |
| `<ar-status-bar>` | `ArStatusBar` | Top OS status bar banner |
| `<ar-git>` | `ArGit` | GitHub Digital Factory dashboard container |
| `<ar-ai>` | `ArAI` | AI Council advisory assistant container |
