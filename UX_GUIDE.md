# Arcanum Cross-Platform UX Guide v2.4

## UX Philosophy: Living Gaming Operating System
The Arcanum user experience eliminates standard web or mobile app boundaries. The interface feels like entering an active digital RPG gaming universe.

## Multi-Modal Input Adaptation
- **Touch Interaction**: Single tap, long press haptics, swipe navigation, pinch zoom, pointer reaction ripples.
- **Desktop & Mouse**: Custom cursor reactions, right-click context menus, draggable windows, keyboard shortcuts.
- **Gamepad & TV**: D-Pad arrow key spatial focus navigation with glowing focus rings.
- **Android Native**: Edge-to-Edge window insets, Predictive Back gestures, haptic feedback.
