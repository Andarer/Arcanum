# Arcanum Network & Cross-Device Link Protocol v2.4

## Network Layers & Transports
Arcanum Evolution provides offline-first P2P and cross-device networking through the **Arcanum Link Protocol (ALP v2.0)** across multiple transports:
- **QR Code Scanning & Generation**: Camera scanning and visual QR code payload exchange.
- **Universal Links (`arcanum://link`)**: Protocol handler for deep-linking cards, worlds, and saves.
- **Clipboard & Share API**: One-click base64 JSON payload copying and system sharing.
- **WebRTC P2P**: Direct browser-to-browser data channel peer connections.
- **Local Network / Bluetooth / NFC**: Native Android bridge transport interfaces.
